# Day 6 — ATS Resume Optimizer

## 🎯 Objective

Learn how Claude can help optimize a resume for Applicant Tracking Systems (ATS) and improve recruiter readability while keeping all information truthful.

## 📌 Task

I used Claude with an ATS Resume Optimizer prompt to analyze and improve a resume.

The goal was to:

- Improve ATS parsing
- Improve recruiter readability
- Optimize resume structure
- Use stronger action verbs
- Remove unnecessary repetition
- Create a professional one-page resume
- Keep all information truthful

## 🧠 What I Learned

### 1. ATS Optimization
Applicant Tracking Systems scan resumes before they reach recruiters. A clear structure and appropriate keywords can make a resume easier for ATS software to parse.

### 2. Recruiter Readability
A resume should communicate skills, education, experience, and projects clearly and quickly.

### 3. Professional Formatting
ATS-friendly resumes should use simple formatting such as:

- Single-column layout
- Clear section headings
- Plain text contact information
- No tables or unnecessary graphics

### 4. Truthful Optimization
AI should improve the presentation of existing information without inventing:

- Skills
- Projects
- Experience
- Certifications
- Achievements
- Metrics

## 🛠️ Tool Used

- Claude AI
- ATS Resume Optimizer Prompt

## 📋 Prompt Used

The prompt instructed Claude to act as an ATS optimization expert and resume writer.

It asked Claude to:

1. Analyze the existing resume.
2. Provide a short ATS score comparison.
3. Explain the improvements made.
4. Generate an optimized one-page A4 resume.
5. Keep every claim truthful.
6. Avoid inventing missing information.

## 💡 Key Takeaway

The biggest learning from Day 6 was that resume optimization is not only about making a resume visually attractive.

It is about making the content:

**Clear + Relevant + ATS-Friendly + Recruiter-Friendly + Truthful**
