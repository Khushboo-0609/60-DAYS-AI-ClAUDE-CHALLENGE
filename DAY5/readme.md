# ABTalks 60-Day Claude AI Mastery Challenge

## Day 5 – Context Engineering 🧠

### 📚 Topic
Context Engineering

### 🎯 Objective
Learn how providing relevant context to Claude can improve the quality, relevance, accuracy, and personalization of AI-generated outputs.

### 📝 What I Learned

Context Engineering means providing an AI with the relevant background information, goals, constraints, skills, preferences, and other details it needs before asking it to perform a task.

The quality of context can have a major impact on the quality of the final AI output.

### 🔍 Today's Experiment

I compared two prompts that asked Claude to create a 30-day learning roadmap.

**Prompt A – Without Context**
- Asked Claude to create a general 30-day learning roadmap.
- Did not provide personal information or specific requirements.

**Prompt B – With Context**
- Included current situation
- Current skills
- Career goal
- Available time
- Experience level
- Preferred learning style

### ⚖️ Comparison

| Prompt A – Without Context | Prompt B – With Context |
|---|---|
| Generic roadmap | Personalized roadmap |
| Broad recommendations | Goal-specific recommendations |
| More assumptions | Fewer assumptions |
| Less relevant to my situation | More relevant to my situation |
| General learning plan | Actionable learning plan |

### 💡 Key Learning

The experiment showed that adding useful context helps Claude understand the user's situation better and generate more relevant and actionable results.

A good prompt tells AI **what to do**, while good context helps AI understand **who I am, where I am starting from, and what I want to achieve**.

### 🚀 Key Takeaway

Better context → Better understanding → More personalized AI output.
